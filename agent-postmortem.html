Five root causes → the fix

ROOT CAUSE 01 · TASK–PLATFORM MISMATCH

Wrong Craigslist section

It searched /apa (apartments = monthly leases). A $300-total, 3-night stay simply doesn't exist there. Guaranteed zero, no matter how good the agent is.

FixSend it to sfbay.craigslist.org/search/sub — sublets / temporary, where short stays actually live.
ROOT CAUSE 02 · GEO THROUGH TEXT

Neighborhoods typed as keywords

"North Beach Marina" went into the search box as a literal phrase, AND-matched against listing text, and combined two areas into one impossible query.

FixUse the NEIGHBORHOODS filter checkboxes. One neighborhood per run — never both at once.
ROOT CAUSE 03 · AMBIGUOUS BUDGET

$300 total vs monthly, undefined

The agent guessed the budget was monthly-ish and filtered accordingly, surfacing scam-priced junk instead of interpreting "$300 for the whole stay."

FixState it explicitly: $300 TOTAL for 3 nights (~$100/night). Read prices per listing instead of a hard max filter.
ROOT CAUSE 04 · DATES DROPPED

July 18–21 silently ignored

Craigslist has no date filter, so the agent just abandoned the date requirement without saying so. The core ask went unmet invisibly.

FixTell it there is no date filter — open each post and read availability + minimum stay from the body.
ROOT CAUSE 05 · UNDER-CONSTRAINED

The agent free-associates

Given a loose goal, Holo improvised search terms ("furnished", "room", "short term") and thrashed. It needs a script, not a wish.

FixGive rigid, one-variable-at-a-time steps with a required verification step before it's allowed to conclude "zero."
CONFIRMED · NOT A BUG

FB Marketplace needs login

Property Rentals errored out logged-out. This isn't fixable without an account, and it validates the plan.

DecisionCraigslist-only for the core. FB Marketplace stays a stretch goal.

What this means for the plan

The task, as phrased, was unwinnable — and that's the point

A real "$300 / 3-night / Marina" search returns nothing on Craigslist regardless of agent quality. That's not a defect to patch. It's proof the demo must run on a listing you control (a teammate posts it), so the reply lands live and on cue.

Reframe the agent's job: not "find impossible inventory" but "filter and extract correctly, then handle outreach." That plays to the agent's strengths and it's demoable. The corrected prompt below is the retry to run in the H interface.

Corrected prompt — paste into the H agent

You are searching Craigslist for a short-term place to stay.
Follow these steps exactly. Do not skip the verification step.

PARAMETERS
- City: San Francisco (city only, NOT the whole Bay Area)
- Neighborhood: Marina — THIS RUN IS MARINA ONLY. Ignore every other neighborhood.
- Dates: July 18-21, 2026 (3 nights: check-in 18th, check-out 21st)
- Guests: 1
- Budget: $300 TOTAL for the whole 3-night stay (~$100/night). A total, not a monthly rent.

RULES
1. Use Craigslist only. Do NOT use Facebook Marketplace — it requires login.
2. Go to "sublets / temporary", NOT "apartments / housing for rent".
   Sublets/temporary is where short stays live; apartments = monthly leases.
   Navigate to https://sfbay.craigslist.org/search/sub
3. Set the location to San Francisco city (subarea "san francisco" / sfc).
   Do NOT leave it on "all SF bay area".
4. Filter the neighborhood using the NEIGHBORHOODS checkboxes in the left sidebar —
   check "Marina" only. Do NOT type neighborhood names into the keyword box.
5. Do NOT set a hard max-price filter. Read each listing's price and note whether
   it looks monthly or short-term/nightly.
6. Craigslist has NO date filter. Do not filter by date. Open each candidate
   listing and read the post body for available dates and minimum stay.

FOR EACH LISTING return a row:
Title | Price (monthly vs short-term) | Neighborhood | Dates / min stay (or "not stated") | URL

VERIFICATION (required): if Marina returns zero, do NOT stop. Remove the neighborhood
filter and report how many sublets exist in San Francisco total. This tells us whether
the problem is the filter or the inventory. Report that number.

OUTPUT: a table of matching listings, then the verification count.

Run North Beach as a separate session (swap every "Marina" for "North Beach"). To test agent mechanics without the inventory problem, replace the budget line with: "show me everything, sort price low-to-high, ignore budget for this test."
