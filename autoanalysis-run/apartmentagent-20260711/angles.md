# Autoanalysis angles — ApartmentAgent (H Company hackathon demo)

Judging: 5×20 — Technicality · Creativity · Usefulness · Demo · Track/sponsor alignment. Goal: blow away H Company judges tomorrow.

1. **parity-qa** (mandatory) — exercise every feature in a real browser + the whole pipeline; verify it works end to end; report anything broken/slow/confusing. Safety floor.
2. **hcompany-judge** — put yourself in a skeptical H Company judge's head (they BUILT computer-use). Does it show off computer-use impressively? Identify the single most impressive ~90s moment. Include the pitch/narrative that makes it memorable + Track-2 alignment (is the computer-use central + un-fakeable?).
3. **demo-reliability** — what could break LIVE on stage (H quota/concurrency, WhatsApp send, Telegram, macOS perms, live discovery latency, network) and how to bulletproof each; the fallback plan; the rehearsal checklist.
4. **wow-factor** — creativity/spectacle: what would make judges audibly react. High-leverage additions (live Agent View on the projector, the dual browser+desktop computer-use, the negotiation moment) + concrete ways to amplify them before tomorrow.
5. **demo-polish** — quick, high-impact visual/UX wins for the on-screen demo (the map UI, Agent View panel, Telegram messages) that read as "premium product" to judges.
